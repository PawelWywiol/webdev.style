# WCAG Principles (POUR)

The **Web Content Accessibility Guidelines (WCAG)** are based on four core principles known by the acronym **POUR**:

## 1. Perceivable

**Information and user interface components must be presented to users in ways they can perceive.**

Users must be able to **see or hear** the content.

**Key points:**

- Provide **text alternatives** for non-text content (e.g., images, audio, video).
- Create content that can be **presented in different ways** without losing meaning (e.g., responsive design, semantic HTML).
- Ensure **sufficient color contrast**.
- Provide **captions and transcripts** for multimedia.

## 2. Operable

**User interface components and navigation must be operable.**

Users must be able to interact with the interface, regardless of their input method.

**Key points:**

- All functionality must be **accessible via keyboard**.
- Provide users **enough time** to read and interact with content.
- Avoid content that may cause **seizures** (e.g., flashing more than 3 times per second).
- Offer **clear and consistent navigation**.

## 3. Understandable

**Information and operation of the user interface must be understandable.**

Users must be able to comprehend content and how to interact with it.

**Key points:**

- Use **clear and concise language**.
- Ensure content behaves in **predictable ways**.
- Provide **helpful error messages** and **input assistance**.

## 4. Robust

**Content must be robust enough to be interpreted reliably by a wide variety of user agents, including assistive technologies.**

**Key points:**

- Use **clean, valid HTML and ARIA** markup.
- Ensure compatibility with **assistive technologies** and future tools.

### Summary

| Principle          | Description                                              |
| ------------------ | -------------------------------------------------------- |
| **Perceivable**    | Users must be able to perceive the content               |
| **Operable**       | Users must be able to operate the interface              |
| **Understandable** | Users must be able to understand content and interaction |
| **Robust**         | Content must work with current and future technologies   |

> A website that is **Perceivable**, **Operable**, **Understandable**, and **Robust** is more likely to be inclusive and accessible to all users.
